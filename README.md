# Sudan Crops

A bilingual (English / Arabic) guide to turning Sudanese sesame, gum arabic, baobab and hibiscus into export products, with a factory in Saudi Arabia.

- **Value chain**: ten stages from the farm in Sudan to the buyer
- **Start small**: the smallest sensible factory, real companies to learn from, Saudi buyers and competitors
- **Factory plan**: machines, space, power, staff, investment, margin and payback
- **Markets**: who buys each product, where, and in what form
- **Compare crops**: side by side, with pros and cons

Every checked figure shows its source and a trust level. Figures are rough estimates for early planning.

Plain HTML, CSS and JavaScript, no build step. Data lives in `data/*.json`, interface text in `i18n/`.

Run locally with any static file server from this folder, then open `http://localhost:5173`.
Planner self-check: `node js/plan.test.mjs`.
